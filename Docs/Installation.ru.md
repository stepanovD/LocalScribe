# Установка LocalScribe

Эта инструкция описывает сборку LocalScribe из исходного кода на macOS,
первый запуск и настройку. Готового установщика в репозитории пока нет:
приложение собирается локально и подписывается временной подписью для разработки.

## Что понадобится

- Mac с macOS 14 Sonoma или новее;
- учётная запись пользователя с возможностью устанавливать инструменты
  разработчика;
- Xcode или Xcode Command Line Tools со Swift 6;
- Git;
- свободное место для исходников, сборки и модели распознавания речи;
- локальная многоязычная модель whisper.cpp в формате `ggml-*.bin`;
- Obsidian-хранилище или обычная папка, куда LocalScribe сможет записывать
  Markdown-файлы.

Приложение предназначено только для macOS. Модель распознавания не входит в
репозиторий и не скачивается приложением автоматически.

## 1. Установите инструменты разработчика

Откройте Terminal и выполните:

```sh
xcode-select --install
```

Если macOS сообщает, что инструменты уже установлены, переходите к проверке:

```sh
git --version
swift --version
clang --version
xcrun --sdk macosx --show-sdk-path
```

В выводе `swift --version` должна быть указана версия Swift 6.x. Если доступна
более старая версия, установите или обновите Xcode через App Store, один раз
запустите его и выберите установленный Xcode:

```sh
sudo xcode-select --switch /Applications/Xcode.app/Contents/Developer
sudo xcodebuild -license accept
```

## 2. Получите исходный код

На странице репозитория GitHub нажмите **Code**, скопируйте HTTPS-адрес и
выполните команды, подставив этот адрес:

```sh
git clone https://github.com/OWNER/LocalScribe.git
cd LocalScribe
```

Архив **Download ZIP** тоже подходит, но Git удобнее для последующих обновлений.
В репозитории уже находится macOS-библиотека whisper.cpp; отдельно собирать её
не требуется.

## 3. Скачайте модель Whisper

Откройте раздел моделей в официальном репозитории
[whisper.cpp](https://github.com/ggml-org/whisper.cpp/tree/master/models) и
скачайте одну многоязычную модель в формате `ggml-*.bin`. Файлы с суффиксом
`.en` предназначены только для английского языка и не подходят, если нужна
русская речь.

Практичный выбор для первого запуска:

- `ggml-base.bin` — быстрее и экономнее по памяти;
- `ggml-small.bin` — обычно точнее, но требует больше времени и памяти;
- более крупные модели — потенциально точнее, однако заметно тяжелее и медленнее.

Сохраните модель, например, в `~/Models/Whisper/`. Не копируйте её в каталог
проекта: файлы `*.bin` намеренно исключены из Git, чтобы случайно не отправить
большую модель на GitHub.

## 4. Соберите приложение

Из корня репозитория выполните:

```sh
Scripts/build-app-bundle.sh release
```

При первом запуске сборка может занять несколько минут. Готовое приложение
появится здесь:

```text
Build/LocalScribe.app
```

Скрипт собирает Swift- и C++-части, помещает whisper.cpp внутрь приложения,
создаёт bundle и проверяет его подпись. Результат подписан ad hoc и предназначен
для локального запуска, а не для распространения среди других пользователей.

### Необязательно: полная проверка проекта

Перед использованием или публикацией изменений можно запустить весь локальный
набор проверок:

```sh
Scripts/verify-mvp.sh
```

Он выполняет тесты ядра, проверки Swift-кода, короткий нагрузочный тест и
отладочную сборку приложения.

## 5. Установите и запустите

Для постоянного размещения скопируйте приложение в `/Applications`:

```sh
ditto Build/LocalScribe.app /Applications/LocalScribe.app
open /Applications/LocalScribe.app
```

Либо запустите его прямо из каталога сборки:

```sh
open Build/LocalScribe.app
```

LocalScribe работает как приложение строки меню, поэтому отдельное окно после
запуска может не появиться. Найдите значок LocalScribe в верхней строке macOS.

## 6. Выполните первоначальную настройку

1. Нажмите значок LocalScribe в строке меню и откройте **Settings**.
2. В разделе **Obsidian output** выберите папку внутри вашего Obsidian vault.
   Можно выбрать и обычную папку; приложение записывает туда Markdown-файлы.
3. В разделе локальной ASR-модели выберите скачанный файл `ggml-*.bin`.
4. Начните звонок в Zoom, Yandex Telemost, Google Meet или Skype. LocalScribe
   покажет отдельное окно с кнопками **Start Recording** и **Not Now**. Если
   окно не появилось, вернитесь в меню и нажмите **New transcript…**.
5. Прочитайте предложение и нажмите **Start Recording**.

Автоопределение не запускает запись само. Для нативных приложений Zoom,
Yandex Telemost и совместимых клиентов Skype оно использует только локальные
метаданные процессов и активности аудиовхода. Google Meet, Chrome PWA и другие
браузерные звонки также зависят от доступности заголовка окна: macOS может
скрывать его до ранее выданного разрешения Screen Recording, поэтому ручной
запуск остаётся надёжным запасным вариантом.

Если запись была запущена из такого окна, LocalScribe связывает право на
автоостановку с точным идентификатором принятого предложения. Присутствие
звонка при этом оценивается на уровне платформы: другое окно или вкладка той же
платформы считается продолжением звонка, а сигналы других платформ
игнорируются. После десяти последовательных проверок без признаков этой
платформы приложение покажет десятисекундный обратный отсчёт. **Keep Recording**,
закрытие предупреждения или Escape оставляют запись включённой и откладывают
повторное предупреждение на пять минут; восстановившиеся признаки звонка сразу
отменяют ожидание. **Stop Now** завершает запись немедленно. Запись,
запущенная через **New transcript…**, автоматически не останавливается.

Только после явного нажатия **Start Recording** macOS запросит доступ к:

- **Microphone** — для записи вашего голоса;
- **Screen Recording** — для захвата системного звука собеседников.

Разрешите оба доступа. После первого разрешения **Screen Recording** macOS
может потребовать полностью закрыть и снова открыть LocalScribe. Используйте
пункт **Quit** в меню приложения, запустите его заново и повторите начало записи.

Проверить или изменить разрешения можно в **System Settings → Privacy &
Security → Microphone** и **System Settings → Privacy & Security → Screen &
System Audio Recording** (название второго раздела зависит от версии macOS).

## 7. Запишите первую расшифровку

После начала записи в меню доступны пауза и остановка. Можно в любой момент
нажать **Stop**; для записи, запущенной из предложения обнаруженного звонка,
также действует описанное выше предупреждение об автоостановке. LocalScribe
сохранит итоговый Markdown-файл в выбранной папке; открыть последний файл можно
из меню приложения.

Во время записи модель и аудио обрабатываются локально. Приложение не требует
сетевого подключения для цепочки от захвата звука до Markdown-файла.

## 8. Сохраните профиль голоса

В текущем или последнем завершённом звонке выберите анонимного собеседника
`Speaker N`, укажите имя в поле **Name this speaker** и нажмите **Save**. Профиль
создаётся только по этому явному действию: LocalScribe не сохраняет
автоматически голоса всех участников. После сохранения приложение заново
публикует Markdown этого звонка с выбранным именем.

В следующих звонках имя подставляется только при строгом совместимом совпадении.
Короткий, неоднозначный, повреждённый или несовместимый образец остаётся
`Speaker N` и не останавливает расшифровку. Список профилей, переименование и
удаление находятся в **Settings**. Эти действия не переписывают автоматически
все старые файлы.

В профиле хранится локальный компактный акустический дескриптор, а не исходная
аудиозапись. Чтобы имя можно было добавить после звонка, такие ограниченные по
размеру дескрипторы удалённых финальных реплик сохраняются в локальном журнале
восстановления ещё до создания профиля; это не присваивает голосу личность
автоматически. Тем не менее это чувствительные данные, производные от голоса.
Текущая версия не заявляет отдельное шифрование профилей внутри приложения или
гарантированное криминалистическое стирание из SSD, резервных копий и служебных
данных SQLite. Удаление профиля останавливает будущие совпадения, но не удаляет
дескрипторы из уже сохранённых строк журнала звонков. Распознавание профиля —
удобная подпись, а не биометрическая аутентификация или доказательство личности.

## Обновление

Если репозиторий был клонирован через Git:

```sh
cd /путь/к/LocalScribe
git pull --ff-only
Scripts/build-app-bundle.sh release
ditto Build/LocalScribe.app /Applications/LocalScribe.app
```

Перед заменой приложения остановите запись и завершите LocalScribe через
**Quit**. Выбранные папка и модель хранятся как защищённые закладки macOS и
обычно не требуют повторного выбора после пересборки.

## Удаление

1. Остановите активную запись и выберите **Quit**.
2. Переместите `/Applications/LocalScribe.app` в Корзину.
3. При необходимости удалите выданные разрешения в **System Settings → Privacy
   & Security**.

Расшифровки в Obsidian или другой выбранной папке автоматически не удаляются.
Исходный код, модель и каталог сборки также остаются на месте, пока вы не
удалите их самостоятельно. Журнал восстановления и профили голосов находятся в
`~/Library/Application Support/LocalScribe`; после полного закрытия приложения
этот каталог можно удалить через Finder, если восстановление звонков и
сохранённые профили больше не нужны. Резервные копии macOS могут сохранять более
раннюю копию каталога отдельно.

## Решение проблем

### `swift: command not found` или требуется Swift 6

Установите актуальный Xcode или Command Line Tools и повторите команды из
первого раздела. После обновления Xcode проверьте активный путь с помощью
`xcode-select -p`.

### Приложение запущено, но окна нет

Это ожидаемо: LocalScribe находится в строке меню macOS. Проверьте верхнюю
панель, включая область скрытых значков.

### Кнопка начала записи недоступна

В **Settings** должны быть выбраны и папка для расшифровок, и модель
`ggml-*.bin`.

### После выдачи Screen Recording запись не начинается

Полностью завершите LocalScribe через **Quit** и откройте снова. Если проблема
сохраняется, проверьте оба разрешения в настройках конфиденциальности macOS.

### Модель не загружается или приложение использует слишком много памяти

Убедитесь, что выбран обычный файл модели whisper.cpp `ggml-*.bin`, а не архив.
Попробуйте меньшую многоязычную модель, например `ggml-base.bin`.

### Сборка завершается ошибкой

Сначала проверьте инструменты:

```sh
swift --version
xcrun --sdk macosx --show-sdk-path
```

Затем удалите только локальные результаты Swift-сборки и повторите сборку:

```sh
swift package clean
Scripts/build-app-bundle.sh release
```

Если ошибка остаётся, приложите к обращению полное сообщение Terminal, версию
macOS, модель Mac (`Apple menu → About This Mac`) и вывод `swift --version`.
